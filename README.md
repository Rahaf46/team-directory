# Team Directory

A simple and responsive team directory built with React and Vite.

## Project Description

Team Directory is a web application that displays team members using reusable React components.

## Features

- Displays team member images, names, and job titles.
- Uses a reusable `TeamMember` component.
- Passes member information through Props.
- Uses `map()` to render multiple team members.
- Includes responsive styling for different screen sizes.

## Technologies Used

- React
- JavaScript
- Vite
- CSS

## Getting Started

1. Clone the repository.
2. Install dependencies:

   ```bash
   npm install
   ```

3. Start the development server:

   ```bash
   npm run dev
   ```

## Build

To create a production build, run:

```bash
npm run build
```
